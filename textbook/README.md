# Java Silver 教材(単元別)

毎日のクイズ(`../quiz/`)と同じ24単元の読み物です。1単元は「ひとことで言うと → 基本 → 試験のひっかけ → 確認ミニ問題(3問)」の構成です。

- 順番に読む必要はなく、忘れたところ・間違えたところだけ読めます。
- ミニ問題の答えは折りたたまれています。解いてから開いてください。
- コード例の出力は `// 出力:` の行で示してあり、`scripts/verify_textbook.py` で実際に実行して確認します。
- 公式の試験内容チェックリスト(1Z0-825-JPN)と照合済み(2026-11-03)。公式に明記のない補足(Integer キャッシュ、List.of、ビット演算、初期化ブロックなど)も一部含みます。
