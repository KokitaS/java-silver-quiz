# 05 テキストブロック

> ひとことで言うと: `"""` で囲むと、複数行の文字列をそのまま書ける。インデントは「閉じ `"""` の位置」と「いちばん左の行」で決まる。

読む目安: 6分 / 公式カテゴリ: 2 基本データ型・文字列 / 弱点: 末尾の改行と strip()

## 基本

### 書き方
```java
public class Main {
    public static void main(String[] args) {
        String a = """
                Hello
                Java
                """;
        System.out.println(a.length());   // "Hello\nJava\n" → 11
        String b = """
                Hello
                Java""";
        System.out.println(b.length());   // 閉じ """ が最後の行にあるので末尾の改行なし → 10
    }
}
// 出力: 11
// 出力: 10
```

ルール:
- 開始の `"""` の**直後は必ず改行**。同じ行に文字を書くとコンパイルエラー。
- 閉じ `"""` を**独立した行**に置くと、最後の行の末尾に**改行が入る**。文字の直後に置くと入らない。
- **インデント**は、全行(と閉じ `"""` の行)の中で一番左の位置を基準に、共通の空白が取り除かれる。
- 行末の空白は取り除かれる。
- `"` はそのまま書ける(`\"` 不要)。`\n`、`\t` などのエスケープも使える。
- 行末の `\` で、その行の改行を打ち消して次の行とつなげられる。

### strip() は前後だけ
`strip()`・`trim()` は**文字列の前後の空白(改行含む)**を取るだけ。**途中の改行は残る**。

```java
String t = """
        A
        B
        """;
System.out.println(t.strip().length());  // "A\nB" → 3(末尾の改行は消えるが途中は残る)
```

## 試験のひっかけ

| ひっかけ | 正しい理解 |
|---|---|
| 閉じ `"""` を独立行に置く | 最後に改行が入る(長さが +1) |
| `"""Hello` と同じ行に書く | コンパイルエラー |
| `strip()` で途中の改行も消える? | **消えない**(前後だけ) |
| 閉じ `"""` を左にずらす | 共通インデントが減り、先頭に空白が残る |
| テキストブロック内の `"` | エスケープ不要 |

## 確認ミニ問題

**Q1.** 次のコードの `s.length()` は?
```java
String s = """
        ab
        cd
        """;
```
1. 4
2. 5
3. 6
4. コンパイルエラー

<details><summary>答え</summary>

**3**。`"ab\ncd\n"`(閉じ `"""` が独立行なので末尾に改行あり)で 6 文字。

</details>

**Q2.** 次のコードはどうなる?
```java
String s = """Hello
        World""";
```
1. `Hello\nWorld`
2. `HelloWorld`
3. コンパイルエラー
4. 実行時エラー

<details><summary>答え</summary>

**3**。開始の `"""` の直後は改行でなければならない。

</details>

**Q3.** `s.strip()` について正しいのは?

1. 前後の空白だけでなく、途中の改行も消える
2. 前後の空白(改行含む)だけが消え、途中の改行は残る
3. 末尾の改行だけが消える
4. 何も消えない

<details><summary>答え</summary>

**2**。前後だけ。途中の改行は残る。

</details>
